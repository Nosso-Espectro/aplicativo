# Constituição — TEAr

Versão documental: 1.0.0. Data: 2026-09-23. Estado: proposta para revisão do maintainer; não implica release do app.

1. GitHub Issues e Milestones são a fonte de verdade de produto. Cada requisito aponta à origem; lacunas funcionais ficam abertas até decisão explícita.
2. Uma milestone possui uma spec; uma Issue possui uma história e uma branch curta. Specs não impõem branches de milestone.
3. Main é a única trunk. Mudanças pequenas, integráveis e rastreáveis por commits, PRs e tags anotadas após conclusão.
4. React Native é diretriz; o aplicativo ainda não foi inicializado. Primeira versão sem backend. Bibliotecas, linguagem e persistência dependem de decisão técnica fundamentada.
5. Respeitar controle do usuário, acessibilidade e privacidade. Não apresentar apoio como diagnóstico/tratamento. Não introduzir transmissão de dados ou estímulos automáticos sem requisito.
6. Definition of Ready, Definition of Done e quality gate estão em [workflow](../../docs/development-workflow.md). Falta de suíte/build não aprova uma release.
7. Especificações e planos são revisáveis; GitHub prevalece no produto. Mudanças de princípio devem registrar motivo e atualizar AGENTS.md, workflow e templates afetados.

A preparação inicial de 2026-09-23 cobre somente leitura do backlog, documentação, Skills, scripts e validação local, sem implementação de Issues, branches, commits, PRs, tags, push, merge, fechamento de Issues ou alteração de milestones. Em tarefas futuras, respeitar o escopo e as ações explicitamente autorizadas na solicitação vigente.
