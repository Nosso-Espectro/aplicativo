# Tasks — nome da milestone

Vincular spec e plan. IDs locais à spec; uma seção por história/Issue. Caminhos devem refletir a stack real ou ser identificados como propostas. Não marcar conclusão sem evidência.

## US-XXX — Issue #N

- [ ] T001 [US-XXX] Alteração pequena em módulo definido, vinculada a RF/critério e resultado verificável.
- [ ] T002 [US-XXX] Cenário de teste do comportamento e das falhas pertinentes.
- [ ] T003 [US-XXX] Revisar acessibilidade/privacidade aplicáveis e registrar checks no PR.

Use [P] apenas quando a tarefa for independente de arquivos e contratos de outras tasks. Não usar uma task para implementar outra Issue.
