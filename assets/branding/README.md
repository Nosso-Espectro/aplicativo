# Identidade TEAr

Issue [#52](https://github.com/Nosso-Espectro/aplicativo/issues/52).
`tear-icon.png`: imagem raster gerada com a ferramenta nativa image_gen em
2026-10-13, a partir da fotografia da capa fornecida diretamente pelo usuário.
O usuário aprovou expressamente esta imagem como ícone. Arquivo copiado sem
alterar pixels; não contém a fotografia, dedos ou os textos editoriais da capa.
Isso não representa revisão jurídica dos direitos da obra de referência.

## Prompt usado

Logo-brand para o aplicativo TEAr, inspirada na capa: silhueta clara de cabeça
voltada para a esquerda, fundo azul-marinho, faixa diagonal laranja inferior e
pequeno sol azul-claro; lettering horizontal exato TEAr (TEA maiúsculo, r minúsculo).
Gráfico quadrado, contraste alto, margens de segurança e linguagem adulta/neutra.
Sem fotografia, dedos, livro, textos editoriais, slogans, quebra-cabeça, sombras,
3D ou moldura de mockup. A imagem gerada/aprovada tem 1254 por 1254 pixels;
Expo CNG deriva os tamanhos nativos necessários durante o build remoto.

## Uso

Ícone Android/iOS, favicon web, marca no quadro e SplashScreen nativa com fundo
azul-marinho. A imagem é empacotada localmente; não há download ao abrir o app.
Splash desaparece quando o app está pronto, conforme o comportamento padrão do
Expo Router, sem áudio, timer ou fade configurado. Android pode aplicar máscara
do launcher/Android 12+; prévia web não equivale ao splash de um APK Release.
